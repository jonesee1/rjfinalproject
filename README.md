# Contact Center Modernization Analysis

## Project Purpose
The goal is to find a modern Contact Center solution that provides a seamless Omni Channel solution allowing Agents and Customers to use their Channel of choice (voice, chat, self-service etc.) and be able to switch between those channels without losing context.  This is analysis of vendors, not the actual implementation.  The output of this is a project proposal for executive management to evaluate and approve.

## Project Repository Structure
This project contains a document folder (/docs) that includes the full scope (scope.md), a high level plan/WBS (plan.md) and a retrospective file (retrospective.md) with lessons learned from putting this proposal together.  There is also an html page explaining the project and a link to more detail about the project.
